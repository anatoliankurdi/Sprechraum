# Sprechraum iOS preview

Open `Sprechraum/Sprechraum.xcodeproj` with Xcode and run the `Sprechraum` scheme on an iPhone simulator.

The preview loads the existing local Sprechraum server at `http://127.0.0.1:4173`. Keep `server.mjs` running while testing. This first native preview intentionally leaves the existing web app untouched; on-device AI and offline packaging are the next mobile stage.
